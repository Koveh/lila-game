# Лила — современная веб-версия

React + Vite. Соло-партия с Проводником и Судьёй.

## Как играть

1. Сформулируй вопрос (не да/нет).
2. Кидай кубик, пока не выпадет **6** — игра пускает на клетку «Рождение».
3. Ходи по 72 клеткам. Читай смысл клетки. Слушай Проводника и Судью.
4. Стрелы ↑ поднимают, змеи ↓ спускают.
5. Цель — клетка **68** (космическое сознание). Ход дальше 68 не засчитывается.

Ряды = чакры: от физической опоры к связи с душой.

## Запуск

```bash
cd /root/games/lila
npm install
npm run dev
```

Открыть: http://127.0.0.1:5177/

## Стек

- React 19 + TypeScript
- Vite
- Без бэкенда: голоса Проводника/Судьи — шаблоны по клетке и вопросу
